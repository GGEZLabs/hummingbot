# Repository Overview

| Repository | Description |
| ----- | ----- |
| [Hummingbot API](https://github.com/GGEZLabs/hummingbot-backend-api) | REST API backend for managing bots, portfolios, and trading |
| [Hummingbot Client](https://github.com/GGEZLabs/hummingbot) | Core trading client with CLI interface for CEX trading |
| [Gateway](https://github.com/GGEZLabs/hummingbot-gateway) | DEX middleware for Uniswap, PancakeSwap, Raydium, and 30+ DEXs |
| [deploy](https://github.com/GGEZLabs/hummingbot-deploy) | repository provides a streamlined Docker Compose environment for deploying Hummingbot strategies.  |
| [hummingbot-api-client](https://github.com/GGEZLabs/hummingbot-api-client) | An async Python client for the Hummingbot API with modular router support. |
| [Dashboard](https://github.com/GGEZLabs/hummingbot-dashboard) | Web-based UI for bot management  |
