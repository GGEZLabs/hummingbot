# CLI Clipboard Operations Guide

This section outlines the standard procedures for copying and pasting text within the Command Line Interface (CLI) on Linux environments.

## 1. Pasting Text into the CLI

Depending on your specific terminal emulator settings, the keyboard shortcuts for pasting may vary.

* Standard Method:
  Press Ctrl \+ V or use the Right-Click mouse button.

* Linux Terminal Alternative:
  If the standard commands are reserved by the system, use Shift \+ Ctrl \+ V. Alternatively, hold the Shift key while performing a Right-Click.

## 2. Copying Text from the CLI

To select and copy text while the CLI application is running, follow these steps to bypass the interface's default mouse capture:

1. Hold down the Alt key.

2. While holding Alt, click and drag to select the desired text.

3. Press Ctrl \+ C to copy the selection to your clipboard.
